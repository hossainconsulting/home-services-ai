# Create a learning plan

**Placeholders:** `[skill or subject]`, `[specific outcome]`, `[current level]`, `[hours per week]`, `[deadline]`

Convene five learning advisors: a subject expert, curriculum designer, practical
coach, memory specialist, and skeptical evaluator.

I want to learn [skill or subject] so I can [specific outcome]. My current level
is [beginner/intermediate], I have [hours] per week, and my deadline is [date or
timeframe].

Let each advisor propose an approach and challenge unnecessary or unrealistic
steps. Synthesize their advice into a week-by-week roadmap with learning
resources to look for, practice exercises, milestone projects, and a clear way
to test my progress.
